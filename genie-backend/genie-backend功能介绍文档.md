# Genie-Backend 功能介绍文档

## 项目概述

Genie-Backend 是一个基于 Spring Boot 3.2.2 和 Java 17 开发的智能数据分析代理服务，实现了 JoyDataAgent 智能问数框架。该项目集成了多智能体协作、数据治理、自然语言转SQL、向量检索等核心功能，是一个完整的智能数据分析平台。

## 技术架构

### 核心技术栈
- **Spring Boot 3.2.2** - 主框架
- **Java 17** - 编程语言
- **MyBatis-Plus** - 数据持久化框架
- **Qdrant** - 向量数据库
- **Elasticsearch** - 全文检索
- **OkHttp** - HTTP客户端
- **Jackson** - JSON处理
- **Lombok** - 代码简化工具

### 数据库支持
- **MySQL** - 关系型数据库
- **ClickHouse** - 分析型数据库
- **H2** - 内存数据库（测试环境）

## 核心功能模块

### 1. 智能问数功能

#### 1.1 自然语言转SQL（NL2SQL）
- **功能描述**: 将自然语言查询转换为标准SQL查询语句
- **技术实现**: 基于大语言模型的语义理解和SQL生成
- **性能表现**: 在 Birdsql 公开榜单上达到 75.74% 的准确率，排名第4位

**主要特性**:
- 支持复杂查询语义理解
- 多表关联查询生成
- 聚合函数和窗口函数支持
- 时间维度查询处理

#### 1.2 TableRAG技术
- **两阶段动态选表选字段**:
  - 第一阶段：基于向量相似度的粗筛
  - 第二阶段：基于语义理解的精筛
- **Schema召回**: 智能选择相关表和字段
- **上下文优化**: 减少无关信息干扰

### 2. 多智能体协作框架

#### 2.1 智能体架构
- **BaseAgent**: 所有智能体的基类，提供状态管理和执行框架
- **ReActAgent**: 推理-行动智能体，支持循环推理和工具调用
- **PlanningAgent**: 规划智能体，负责任务分解和执行规划
- **ExecutorAgent**: 执行智能体，专注任务执行
- **SummaryAgent**: 总结智能体，负责结果汇总和分析

#### 2.2 协作模式
- **React模式**: 推理-行动循环，适合复杂问题解决
- **Plan&Solve模式**: 计划-解决模式，适合结构化任务
- **工具调用**: 支持并发工具调用和结果聚合

### 3. 工具生态系统

#### 3.1 内置工具集
- **CodeInterpreterTool**: 代码解释器，支持Python代码执行
- **DataAnalysisTool**: 数据分析工具，提供统计分析功能
- **DeepSearchTool**: 深度搜索工具，支持多源数据检索
- **FileTool**: 文件处理工具，支持文件上传下载和格式转换
- **ReportTool**: 报告生成工具，支持多种格式输出

#### 3.2 MCP工具集成
- **Model Context Protocol**: 支持标准化工具协议
- **可扩展架构**: 易于集成第三方工具
- **工具组合**: 支持工具链式调用

### 4. 数据治理与处理

#### 4.1 DGP数据治理协议
- **表设计原则**: 明细表和指标表分离
- **字段设计原则**: 避免字段混淆，明确时点/时期指标
- **字段值设计**: 枚举值语义说明
- **数据质量**: 数据一致性和完整性保障

#### 4.2 多数据源适配
- **JDBC抽象层**: 统一的数据访问接口
- **方言支持**: 支持不同数据库的SQL方言
- **连接池管理**: 高效的数据库连接管理
- **事务处理**: 完整的事务支持

### 5. 向量检索与语义搜索

#### 5.1 向量数据库集成
- **Qdrant集成**: 高性能向量数据库
- **Embedding生成**: 支持多种嵌入模型
- **相似度搜索**: 高效的向量相似度计算
- **混合检索**: 向量检索与传统检索结合

#### 5.2 语义检索功能
- **字段语义理解**: 基于字段描述的语义匹配
- **同义词扩展**: 支持同义词和相关词检索
- **上下文感知**: 基于查询上下文的智能检索

### 6. 流式数据传输

#### 6.1 SSE流式接口
- **实时数据传输**: Server-Sent Events 流式传输
- **心跳机制**: 保持连接活跃状态
- **断线重连**: 自动重连机制
- **流量控制**: 支持背压处理

#### 6.2 多格式输出
- **HTML输出**: 富文本格式展示
- **Markdown输出**: 标准文档格式
- **Excel输出**: 表格数据导出
- **JSON输出**: 结构化数据交换

### 7. API接口体系

#### 7.1 智能问数接口
- `POST /api/v1/chat/query` - 流式问数接口
- `POST /api/v1/chat/api` - API问数接口
- `POST /api/v1/vector/recall` - 向量召回接口
- `POST /api/v1/es/recall` - ES召回接口

#### 7.2 模型管理接口
- `GET /api/v1/models` - 获取所有数据模型
- `POST /api/v1/preview` - 数据预览
- `POST /api/v1/nl2sql` - NL2SQL转换

#### 7.3 智能体接口
- `POST /api/v1/agent/auto` - 智能体自动执行
- 支持多种工具集成
- 支持流式响应
